# Machine Learning Projects Repository 🚀

A curated collection of end-to-end Machine Learning, Exploratory Data Analysis (EDA), and Data Science projects.

---

## 📂 Projects

| Project | Description | Tech Stack |
| :--- | :--- | :--- |
| [**Car Selling Price Prediction**](./Car%20Selling%20Price%20Prediction) | Machine learning project predicting used car selling prices based on vehicle features and usage. | Python, Jupyter, Scikit-learn, Pandas |
| [**Laptop Price Predictor**](./Laptop%20Price%20Predictor) | Web application predicting laptop prices based on hardware specifications and brand. | Python, Flask, Scikit-learn, Pandas |
| [**Mushroom Classification**](./mushroom_classification) | Web application classifying mushrooms as edible or poisonous based on physical characteristics. | Python, Django, Scikit-learn |
| [**Car Market Trends Analysis**](./Car%20Market%20Trends%20Analysis%20with%20Car%20Dekho%20Data) | Exploratory Data Analysis (EDA) analyzing car market pricing trends using CarDekho data. | Python, Jupyter, Pandas, Seaborn |
